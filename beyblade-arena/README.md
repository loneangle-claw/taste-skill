# 戰鬥陀螺 ARENA

一個可以在瀏覽器直接玩、也能開房間跟朋友線上 1v1 的戰鬥陀螺遊戲。
純 JavaScript，前端零框架、零打包工具，後端只有一個 Node 檔案（唯一相依套件是 `ws`）。

## 快速開始

```bash
cd beyblade-arena
npm install
npm start
# 打開 http://localhost:3000
```

線上對戰：一邊按「建立房間」拿到 4 碼房號，另一邊輸入房號加入，兩人就會直接進入戰鬥。
同一個區網或有公開網址時，把 `http://<你的IP>:3000` 給朋友即可。

## 玩法

| 動作 | 1P（單人／線上） | 2P（雙人同機） |
| --- | --- | --- |
| 蓄力發射 | 按住 `空白鍵`，量表衝高時放開 | 按住 `Enter` |
| 移動 | `W` `A` `S` `D` 或方向鍵 | 方向鍵 |
| 衝刺撞擊 | `空白鍵`（戰鬥中） | `Enter` |

也支援滑鼠／手指：在場地上拖曳即可操控自己的陀螺。

**計分**（先拿 4 分獲勝）

| 勝法 | 條件 | 分數 |
| --- | --- | --- |
| 迴轉結束 | 對手迴轉力歸零 | +1 |
| 場外結束 | 把對手撞出場外 | +2 |
| 爆裂結束 | 打滿對手的爆裂量表 | +3 |
| 時間到 | 90 秒後迴轉力較高者 | +1 |

## 改裝系統

陀螺由 **層片 Layer + 圓盤 Disc + 軸心 Driver** 三個部位組成，數值相加後決定物理參數：
攻擊、防禦、持久、抗爆、重量、抓地力、地板摩擦、迴轉衰減率。旋轉方向也能選——
**逆旋對戰時雙方的迴轉力消耗都會提高 35%**（吸迴轉），是高風險高報酬的選擇。

四種原型的個性差異來自數值而非特例程式碼：

- **衝鋒型**：攻擊高、迴轉衰減快，靠場外與爆裂速殺。
- **鐵壁型**：防禦與抗爆極高，很難被打死，但自己也殺不了人。
- **持久型**：迴轉衰減最慢，但抗爆最低，怕被持續猛攻。
- **全能型**：各項中庸，重量高，碰撞時比較不會被推走。

## 平衡怎麼調

`public/js/physics.js` 最上方的 `TUNE` 物件集中了所有戰鬥平衡參數，
`scripts/balance.mjs` 會用 CPU 互打的方式跑完整對戰矩陣：

```bash
npm run balance        # 每組對戰跑 50 場，印出勝率矩陣與勝法分佈
```

目前的數據（每組 60 場、共 960 場）：

```
平均一回合 30 秒
勝法分佈：迴轉結束 64% · 爆裂結束 23% · 場外結束 12%
四種原型整體勝率 40% ~ 53%（樣本數不大，重跑會有 ±8% 的浮動）
```

老實說：目前四種原型大致堪用、沒有哪一種完全無敵，但還不是漂亮的剪刀石頭布，
鐵壁型偏弱一些。要繼續調的話，改 `TUNE` 或 `parts.js` 的數值再重跑就好。

改動 `TUNE` 之後重跑一次，就能看到平衡有沒有壞掉。

## 架構

```
server.js              Node HTTP 靜態伺服 + WebSocket 房間轉發（不參與模擬）
public/js/physics.js   純物理模擬，不碰 DOM，瀏覽器與 Node 都能跑
public/js/parts.js     零件表與數值換算
public/js/ai.js        電腦對手（只會寫入 input，跟人類玩家走同一條路徑）
public/js/render.js    Canvas 繪圖、粒子、拖影、震屏
public/js/game.js      回合流程、輸入、連線同步
public/js/main.js      選單、改裝介面、HUD
scripts/balance.mjs    無頭平衡測試
```

### 連線模型

採 **房主權威（host-authoritative）**：房主端跑物理模擬，每秒 30 次送出狀態快照；
訪客端只送自己的操作輸入，收到快照後做插值平滑。伺服器單純轉發訊息、不做模擬，
所以部署成本極低，但也代表房主的網路品質決定體驗品質。

要換成伺服器權威（防作弊）的話，把 `stepBattle` 搬到 `server.js` 裡跑就行——
物理模組刻意沒有相依 DOM 就是為了這件事。

## 部署

任何能跑 Node 且支援 WebSocket 的地方都可以（Railway、Render、Fly.io、自己的 VPS）。
只吃 `PORT` 環境變數：

```bash
PORT=8080 npm start
```

注意：Vercel／GitHub Pages 這類純靜態或無狀態 Serverless 平台無法維持 WebSocket 房間，
單人與雙人同機模式仍可運作，但線上對戰不會通。
