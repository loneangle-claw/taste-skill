不只教你寫腳本

從釐清業務流程與界定測試範圍與案例，透過 Playwright 與 AI Agent 建立可執行、可診斷、可維護的 UI 自動化測試工作流。

不只教你寫腳本，更涵蓋測試案例設計、Evidence 診斷、POM 與團隊測試流程。

貫穿案例：Pet Shop 寵物購物系統

課程以「Pet Shop 寵物購物系統」的購物主流程作為貫穿案例，從業務流程、測試案例、Playwright 自動化一路延伸到失敗診斷與可維護測試架構，建立一套能實際應用於開發與測試工作的 UI 自動化測試流程。

  1. 業務流程界定測試範圍
  2. 測試案例拆分 Scenario 與 Test Case
  3. Playwright 腳本結合 AI Agent 協作
  4. 失敗診斷Screenshot、Trace 與 Evidence
  5. 可維護架構POM、Fixture 與團隊測試流程

常見問題與備註

這門課會教 Playwright 的基本操作嗎？
會，並會從基本腳本一路串到測試案例設計、AI Agent 協作、失敗診斷與 POM 測試架構。
需要具備 Playwright 經驗嗎？
不需要熟悉 Playwright，但建議具備基本程式與網頁概念。
課程會使用哪些工具？
主要使用 Playwright Test、CLI 與相關 Skill / MCP，並搭配 VS Code 與 Codex 或 Claude 等 AI Agent 開發工具；但不限定使用特定單一 AI Coding 工具。
需要從零開發 Pet Shop 系統嗎？
不需要。Pet Shop 是課程提供的範例系統，主要用來作為 UI 自動化測試與流程驗證的練習對象。
會提供課程錄影嗎？
會提供完整課程錄影，方便課後複習與反覆練習。
