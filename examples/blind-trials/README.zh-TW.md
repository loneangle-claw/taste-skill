# 盲測作品

[English](README.md) | **繁體中文**

這裡的每一頁都由一個代理生成。它只拿到一份需求，並被要求只讀 `skills/taste-skill/SKILL.md`，從頭到尾沒看過 `tests/preflight/` 裡的檢查工具。生成後，每一頁都用該工具檢查過。

| 頁面 | 需求 | 結果 |
| --- | --- | --- |
| [`workshop/`](workshop/) | 週末插花工作坊的報名頁。沉穩、現代、帶點質感。 | 34 / 34 |
| [`saas/`](saas/) | 一個開發者工具的首頁，這個工具會在 CI 裡檢查行銷頁面。 | 34 / 34 |
| [`portfolio/`](portfolio/) | 靜物攝影師的作品集。「要有 Awwwards 水準，大膽、有編輯感。」 | 34 / 34 |
| [`course-redesign/`](course-redesign/) | 改版一個繁體中文課程頁，訪客多半從 Facebook 廣告用手機點進來。原頁在 `before.html`。 | 34 / 34（原頁：2 失敗、3 警告） |

每個資料夾另有一張 `preview.webp`，是 1440 x 900 的首屏截圖。

## 全過代表什麼、不代表什麼

全過代表頁面避開了所有量得出來的毛病：對比度、橫向溢出、首屏放得下、eyebrow 數量、禁用字體與配色、破折號、scroll 監聽等等。它不代表頁面好看。有人看過截圖後，找到了規則量不到的問題：

- **`saas`：** 首屏的終端機截圖被裁在行的中間，區塊之間的空白偏大。
- **`portfolio`：** 預約表單左側一大塊是空的。
- **`course-redesign`：** 因為沒有照片可用，桌面版首屏右側留空。

## 內容是範例

- **編造的內容：** 日期、價格、評語、客戶名稱和客戶 logo 都是生成代理編的，每一頁都在 HTML 註解裡標出這些範例內容。
- **虛構的名稱：** Stem & Vessel、Preflight 的定價、Odile Varga 和青嶼軟體學堂都不存在。
- **照片：** 花卉照片裁自 `examples/floria-*.webp`。

## 生成後唯一的修改

skill 原本禁止在範圍中使用 en dash，所以課程頁改版把原頁的 `11/28（六）～11/29（日）` 改成了連字號。這條規則現在已排除中日韓文的波浪號 `～`（SKILL.md §9.G），`course-redesign/index.html` 裡的四處日期也已手動改回。除此之外沒有任何修改。

## 回歸測試

`tests/preflight/preflight.test.mjs` 會檢查這個資料夾裡每一個 `*/index.html`，預期不會有任何失敗或警告。如果出現新的警告，代表檢查工具多了一個誤報，或是某條規則改了。更新頁面之前，請先看過截圖。
