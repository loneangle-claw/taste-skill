# Blind trials

**English** | [繁體中文](README.zh-TW.md)

Each page here was generated by an agent that was given one brief and told to
read only `skills/taste-skill/SKILL.md`. It never saw the audit in
`tests/preflight/`. Every page was then audited with that tool.

Each folder also has a `preview.webp` of the first screen at 1440 x 900.

## What a pass means, and what it does not

A pass means the page avoids every measurable tell: contrast, overflow, hero
fit, eyebrow count, banned fonts and colours, dashes, scroll listeners, and
so on. It does not mean the page is good. A person looking at the screenshots
found issues that no rule measures:

- **`saas`:** the terminal screenshot in the hero is cropped mid-line, and the gaps between sections are large.
- **`portfolio`:** the space to the left of the booking form is empty.
- **`course-redesign`:** the desktop hero has empty space on the right, because no photo was available.

## Content is placeholder

- **Invented content:** dates, prices, testimonials, client names and client marks were invented by the generating agent. Each page marks its placeholders in HTML comments.
- **Fictional names:** Stem & Vessel, Preflight's pricing, Odile Varga and 青嶼軟體學堂 do not exist.
- **Photos:** the flower photos are crops of `examples/floria-*.webp`.

## One edit after generation

The skill banned en-dashes in ranges, and the course redesign followed that by turning the source's `11/28（六）～11/29（日）` into a hyphen range. The rule now exempts the CJK wave dash `～` (SKILL.md §9.G), and the four dates in `course-redesign/index.html` were changed back by hand. Nothing else was edited.

## Regression tests

`tests/preflight/preflight.test.mjs` audits every `*/index.html` in this folder and expects no fails or warnings. A new warning means either the checker gained a false positive or a rule changed. Look at the screenshots before you update a page.
